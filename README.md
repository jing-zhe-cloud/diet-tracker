# 饮食记录 (Diet Tracker)

一款单机即用的饮食记录与营养管理桌面应用，双击 `饮食记录.exe` 即可运行，无需安装任何环境。

## 功能特性

- **三餐记录**：按早餐/午餐/晚餐/加餐记录食物与份量，自动累计热量与三大营养素
- **营养目标**：按周一至周日分别设定热量/蛋白质/脂肪/碳水目标，实时查看完成进度与剩余缺口
- **智能食物推荐**：基于当前营养缺口，采用**加权欧氏距离算法**动态匹配食物，推荐份量自动约束在 5g~200g，Top8 结果保证覆盖至少 3 个不同类别
- **1000+ 内置食物库**：覆盖主食、蔬菜、肉类、水产、蛋奶、豆制品、水果、坚果、零食、饮品、油脂、补剂 12 个分类，共 1009 种真实食物（完整清单见 [食物清单_最新.csv](食物清单_最新.csv)）
- **个人本地食物库**：云端库里没有的食物，填写营养值添加餐食后**自动存入你的本地食物库**，下次直接搜索使用；每个账号拥有独立且互相隔离的本地库，本地食物同样参与智能推荐
- **历史与导出**：近 30 天饮食历史一键导出 TXT

## 快速开始

### 方式一：直接运行（推荐）

双击根目录的 `饮食记录.exe`，浏览器访问 <http://127.0.0.1:8080>。数据以 SQLite 形式存储在程序同目录的 `meals.db`，随程序携带、随用随走。

### 方式二：从源码运行

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2. 启动
python launcher.py
```

### 打包 exe

```bash
pip install pyinstaller
pyinstaller 饮食记录.spec --clean -y
# 产物位于 dist/饮食记录.exe
```

## 项目结构

```
├── app.py                 # Flask 主程序（路由、营养计算、推荐算法、数据库初始化）
├── launcher.py            # 启动器（自动打开浏览器）
├── requirements.txt       # 依赖清单
├── 饮食记录.spec           # PyInstaller 打包配置
├── templates/
│   ├── index.html         # 主页面（记录、进度、推荐）
│   └── login.html         # 登录/注册页
└── 食物清单_最新.csv        # 内置食物库完整清单（1009 条）
```

## 技术栈

- **后端**：Python + Flask
- **数据库**：SQLite（内置，零配置）
- **前端**：原生 HTML/CSS/JS，响应式布局
- **打包**：PyInstaller

## 数据说明

- 所有数据（账号、餐食记录、目标、个人食物库）仅保存在本机 `meals.db` 中，不上传任何服务器
- 首次启动自动初始化数据库并灌入 1009 条内置食物数据
