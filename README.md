# 饮食记录 (Diet Tracker)

一款**单机即用**的饮食记录与营养管理桌面应用。双击 `饮食记录.exe` 就能跑，不需要安装 Python、不需要数据库服务、不需要联网注册第三方账号。

> 记三餐、算营养、定目标、智能推荐吃什么 —— 数据全部留在你自己的电脑上。

---

## ✨ 功能总览

### 1. 三餐记录

- 按 **早餐 / 午餐 / 晚餐 / 加餐** 四个餐次记录
- 食物搜索即时联想，精确匹配高亮标记；云端库没有的食物可手动填写营养值直接添加
- 支持任意份量（克），自动按每 100g 数据换算成实际摄入
- 每餐实时汇总热量，当日总计一目了然
- 记录支持编辑与删除，改完立刻重算

### 2. 营养目标

- 四大目标：**热量 / 蛋白质 / 脂肪 / 碳水**
- 可按 **周一至周日** 分别设定（工作日、训练日、休息日各一套），也可设为每天通用
- 顶部进度条实时显示完成度：达标绿色、超标红色
- 每日显示剩余缺口（还差多少热量、多少蛋白质……），为智能推荐提供依据

### 3. 智能食物推荐 🌟

当不知道下一顿吃什么补缺口时，推荐引擎会给出答案：

- **加权欧氏距离算法**：以「当前营养缺口 ÷ 目标值」动态分配各营养素权重 —— 缺蛋白多时优先推高蛋白食物，缺碳水多时优先推高碳水食物
- **份量智能建议**：不只是推荐"吃什么"，还推荐"吃多少克"，份量自动约束在 **5g ~ 200g** 合理区间
- **类别多样性保证**：Top8 结果强制覆盖 **至少 3 个不同类别**，避免清一色主食或零食
- 你自己添加的本地食物同样参与推荐，并标记为「我的食物」

### 4. 1000+ 内置食物库

共 **1009 种**真实常见食物，覆盖 12 个分类，全部手工校准营养数据（每 100g）：

| 分类 | 数量 | 分类 | 数量 |
|------|-----:|------|-----:|
| 主食 | 177 | 水果 | 92 |
| 蔬菜 | 145 | 蛋奶 | 87 |
| 肉类 | 123 | 零食 | 82 |
| 水产 | 118 | 豆制品 | 68 |
| 饮品 | 55 | 油脂 | 26 |
| 坚果 | 25 | 补剂 | 11 |

> 完整清单见 [食物清单_最新.csv](食物清单_最新.csv)，可直接用 Excel 打开查看。

### 5. 个人本地食物库 🌟

家里自制、餐馆菜品、地方小吃，云端库没有？没关系：

- **自动入库**：添加餐食时填写营养值，保存后自动按「总营养 ÷ 份量 × 100」换算成每 100g 标准存入你的本地库，**下次搜索直接可用**，无需重复填写
- **编辑同样生效**：编辑历史餐食中的自定义食物，同样自动入库
- **智能去重**：同名食物只存一份；云端已有的食物不会被重复存储
- **完全隔离**：每个账号拥有独立且互相隔离的本地库，家人共用一台电脑也互不干扰

### 6. 历史与数据导入导出

- **近 30 天历史**：每日总热量与三大营养素曲线回顾
- **一键导出 TXT**：当天记录导出为制表符分隔文本，方便存档或二次加工
- **TXT 批量导入**：粘贴/上传导出格式文本即可整日恢复记录（`#` 开头为注释行，导入自动替换当日数据）——导出 + 导入构成完整的备份/恢复闭环

### 7. 多账号与隐私安全

- 支持多用户注册登录，密码经哈希加密存储
- **所有数据（账号、记录、目标、本地食物库）仅保存在本机 `meals.db`，不上传任何服务器**
- 换电脑？拷走 `meals.db` 即完成迁移

## 🚀 快速开始

### 方式一：直接运行（推荐，零配置）

1. 从 [Releases](https://github.com/jing-zhe-cloud/diet-tracker/releases/latest) 下载 `DietTracker-v1.0.0.exe`
2. 双击运行，浏览器自动打开 <http://127.0.0.1:8080>
3. 注册一个账号，开始记录

> 无需安装任何东西，单文件即可运行。数据文件 `meals.db` 自动生成在程序同目录。

### 方式二：源码运行

```bash
git clone https://github.com/jing-zhe-cloud/diet-tracker.git
cd diet-tracker
```

- **一键启动**：安装 Python 3.10+ 后双击 `启动.bat` —— 自动创建虚拟环境、安装依赖、启动服务
- **手动启动**：

```bash
pip install -r requirements.txt
python launcher.py
```

### 打包自己的 exe

```bash
pip install pyinstaller
pyinstaller 饮食记录.spec --clean -y
# 产物位于 dist/饮食记录.exe
```


## 📡 API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/register` `login` `logout` | 注册 / 登录 / 登出 |
| GET | `/api/auth/status` | 登录状态 |
| GET / POST | `/api/meals` | 查询 / 添加餐食（添加自定义食物自动入本地库） |
| PUT / DELETE | `/api/meals/<id>` | 编辑 / 删除餐食 |
| GET | `/api/foods/search?q=` | 食物搜索（本地库优先合并） |
| GET | `/api/recommend?date=` | 智能推荐（含本地食物） |
| GET / POST | `/api/targets` | 查询 / 设置营养目标（按星期） |
| POST | `/api/user-foods` | 手动维护本地食物库 |
| GET | `/api/history` | 近 30 天历史汇总 |
| GET | `/api/export?date=` | 导出当日 TXT |
| POST | `/api/import` | 导入 TXT 批量恢复 |

## ❓ 常见问题

**Q：双击 exe 后浏览器没自动打开？**
手动访问 <http://127.0.0.1:8080>。若提示端口被占用，说明已有实例在运行。

**Q：想备份数据？**
拷贝程序同目录的 `meals.db` 即可；恢复时放回原位置。

**Q：想批量添加自家菜品？**
直接在添加餐食时填写营养值，保存即入本地库；或用「导入」功能批量恢复。

**Q：数据会传到网上吗？**
不会。应用完全离线运行，所有数据仅存本机。
